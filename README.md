# ForeDemand 📈

**Calibrated demand forecasting with conformal prediction intervals — applied to India's UPI transaction volumes.**

> *Planning teams need ranges, not point guesses.*

---

## What This Is

ForeDemand forecasts India's monthly UPI transaction volumes and wraps every forecast in **statistically valid 90% prediction intervals** using split-conformal prediction — a distribution-free uncertainty quantification method.

The key measurable result: *do 90% intervals actually contain ~90% of outcomes?*

## Conformal Prediction Intervals

The intervals are **distribution-free** — no Gaussian assumption needed.

**Algorithm (split-conformal):**
1. Split training data: 75% fit, 25% calibrate
2. For each horizon `h`, collect absolute residuals from rolling re-fits on the calibration period
3. The conformal width `q̂_h = ⌈(n+1)·0.90⌉-th` smallest absolute error
4. Interval: `[ŷ_{t+h} − q̂_h, ŷ_{t+h} + q̂_h]`
5. **Marginal coverage guarantee**: P(Y_{t+h} ∈ PI) ≥ 1−α under exchangeability

## Evaluation Metrics

| Metric | Description |
|--------|-------------|
| **MAE** | Mean Absolute Error (millions of transactions) |
| **RMSE** | Root Mean Squared Error |
| **sMAPE** | Symmetric MAPE (%) |
| **MASE** | MAE / Seasonal-Naive MAE — values < 1 beat the baseline |
| **Coverage** | % of test outcomes falling inside the 90% PI |
| **Winkler Score** | Interval loss — penalises width AND misses (lower = better) |
